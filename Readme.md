# Despacho Probabilístico de Energía y Reservas para Microrredes
Despacho energético conjunto de energía y reservas mediante técnicas de optimización probabilística:
- Determinística basado en escenario muestral medio
- Estocástica SAA
- Robusta con soporte muestral
- Distribucionalmente robusta basada en la métrica de Wasserstein
Diseñado para el planeamiento energético de microrredes. Permite programar el intercambio óptimo entre microrredes interconectadas en una multimicrorred completamente aislada de un sistema de distribución, mediante el **método de multiplicadores de dirección alternante** (ADMM) totalmente dsistribuido. Permite:
- Generación de escenarios, muestras de *N* escenarios y conjuntos muestrales
- Prueba en operación del programa de despacho en escenarios
- Evaluación de despacho y operación bajo distintos métodos y parametrizaciones (e.g. análisis de sensibilidad)
- Programación conjunta del despacho en multimicrorredes de manera totalmente distribuida

Librería desarrollada en el marco del trabajo de grado de Maestría
**Optimización distribucionalmente robusta para la gestión energética de microrredes en red**
presentado en febrero de 2026 en la Universidad Nacional de Colombia.
